# Archon's Descent — Google Stitch Prompt Pack

Ready-to-paste prompts for generating character, enemy, boss, treasure, and companion art in [Google Stitch](https://stitch.withgoogle.com). Companion reference: `DESIGN.md` (full art bible — palette, lore, rarity system) and `Ideas/Design.md` (base UI design system).

**How to use this doc:** Copy one "Prompt" block at a time into Stitch. The **Style Prefix** below should be prepended (or set as Stitch's persistent style context, if supported) to every single prompt in this pack so all generated assets share one visual language.

---

## Style Prefix (prepend to every prompt)

```
Dark cyberpunk-infused retro dungeon-crawler game art, "Archon's Descent."
Clean, high-contrast silhouettes readable at small icon size (32-48px).
Palette: deep space base #090d16, surface #131a2c/#1e2942, neon cyan
accent #38bdf8, vitality green #34d399, doom red #fb7185, warning
orange #fb923c. Rarity accent rings: common #94a3b8 (matte/plain),
rare #3b82f6 (tempered sheen), epic #a855f7 (runed glow), legendary
#eab308 (gold trim, active light source). Stylized, atmospheric horror —
NOT gory or hyper-realistic. Painterly pixel-art-adjacent game icon style,
strong rim lighting, glowing edge highlights against dark backgrounds.
No text or UI chrome in the image itself.
```

## 6. Batch Notes for Stitch

- **Consistency pass:** After generating all character/enemy/boss art, run a final consistency check — every asset should share the same lighting logic (dark background, rim/edge glow, no flat front-lit renders) and the same "readable silhouette first" rule.
- **Icon vs. scene composition:** Characters, companions, enemies, and equipment/relics should be generated as clean single-subject icons/portraits (dark or transparent background). Bosses should be generated as larger dramatic scene compositions since they're full-screen encounters in-game, not HUD icons.
- **Rarity is not decorative:** When generating equipment, never apply a rarity's accent color to an item that isn't that rarity — Stitch should treat the rarity ring color as a strict material/lighting rule, not a palette suggestion.
- **Reference `DESIGN.md`** for full lore context on any subject if a generated result feels generic — every subject here ties back to a specific one-line lore hook (e.g. Cinderheart's "grieving fire," Bram's lost brother) that should visibly inform the mood of the piece.
